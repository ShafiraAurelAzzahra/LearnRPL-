# LearnRPL – Mobile Learning Application

## 📌 Deskripsi
LearnRPL adalah aplikasi mobile berbasis Flutter yang dirancang untuk membantu pengguna mempelajari konsep Rekayasa Perangkat Lunak (RPL) dengan cara yang lebih mudah dan interaktif. Aplikasi ini menyediakan materi pembelajaran serta quiz untuk menguji pemahaman pengguna.

Project ini dikembangkan secara mandiri (solo project), mulai dari tahap perancangan UI/UX hingga implementasi aplikasi.

---

## 📱 Fitur Utama
- 📚 Materi pembelajaran Rekayasa Perangkat Lunak  
- 📝 Quiz interaktif untuk menguji pemahaman  
- 🎨 Tampilan UI yang sederhana dan user-friendly  
- 📱 Dapat digunakan di perangkat mobile (Android)
